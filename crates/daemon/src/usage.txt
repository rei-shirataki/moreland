moreland — turn a USB-connected Android tablet into a second monitor

USAGE
    moreland [OPTIONS]
    moreland stop | start | status

    With no options it runs as a daemon: plug the tablet in and a virtual
    monitor appears, unplug it and the monitor disappears.

OPTIONS
    --max-width <PX>    cap on auto-detected width     [default: 1920]
    --native            stream the tablet's full panel resolution
    --width <PX>        pin width  (requires --height)
    --height <PX>       pin height (requires --width)
    --fps <N>           virtual output refresh rate    [default: 90]
                        120 measures better still; 144 saturates
                        Kirin 659 tablets (hi6250) default to 60 instead
    --bitrate <KBPS>    H.264 target bitrate           [default: 20000; 12000 on hi6250]
    --max-in-flight <N> unacknowledged frames before dropping [default: 3; 2 on hi6250]
    --cavlc             CAVLC instead of CABAC (cheaper for weak decoders)
    --target-usage <N>  encoder speed/quality, 1..7       [default: 3]
    --position <X>      x offset of the virtual output [default: 1920]
    --position-y <Y>    y offset of the virtual output [default: 0]
                        default sits right of a primary at 0x0, no wider than
                        1920px; override either axis to fit your layout
    --scale <F>         display scale of the virtual output [default: 1.25]
                        higher = larger UI (Hyprland)
    --output-name <NAME>
                        name of the virtual output      [default: moreland]
                        required on labwc, which cannot create one and must
                        be pointed at an existing headless output
    --show-cursor       composite the mouse cursor into the stream
    --no-touch          do not forward the tablet's touches to the host
                        (needs write access to /dev/uinput otherwise; if it
                        is missing, touch is skipped and video continues)

    --once              stream one session, then exit
    --seconds <N>       stop after N seconds (implies --once and --stats)
    --stats             print round-trip latency statistics on exit
    -h, --help          show this help

COMMANDS (for a daemon that is already running)
    stop                stop streaming; the daemon keeps running, and the
                        tablet stays stopped until it is unplugged and
                        plugged back in, or until `moreland start`
    start               resume streaming after `moreland stop`
    status              show what the daemon is doing

NOTES
    The tablet needs the companion app installed and USB debugging enabled.
    Diagnostics from the device:  adb logcat -s Moreland

    Resolution is detected from the tablet's panel and matched to its aspect
    ratio, capped at --max-width. Pass --width and --height together to pin it.
